# Battleship vs AI

人間のプレイヤー1人がAI（コンピューター）と対戦できる、シンプルなWeb版 **Battleship（海戦ゲーム）** です。
マス目に隠れた相手の船の位置を予想して攻撃し、先に相手の船をすべて沈めた方が勝ちです。

- **遊ぶ**: https://lightblue-emyu.github.io/battleship-vs-ai/
- **しくみの解説（初心者向け・図あり）**: [docs/how-it-works.md](docs/how-it-works.md)
- **見つけたバグと修正内容**: [docs/bug-report.md](docs/bug-report.md)

## 遊び方

1. **船を配置する**：自分の海域をクリックして5隻（空母5・戦艦4・巡洋艦3・潜水艦3・駆逐艦2）を置きます。
   「向きを変える」または `R` キーで縦横を切替。「ランダム配置」でおまかせもできます。
2. **ゲーム開始**：すべて置いたら「ゲーム開始」を押します。
3. **攻撃する**：敵（AI）の海域のマスをクリック。`✕`（赤）が命中、`•` が外れです。船の全マスに命中すると撃沈。
4. **AIの攻撃**：あなたの攻撃の後、AIが自動であなたの海域を攻撃します。
5. **勝敗**：相手の船を先に全部沈めた方の勝ち。「もう一度遊ぶ」/「最初からやり直す」で再スタートできます。

## 機能

| 要件 | 実装 |
| --- | --- |
| 操作しやすい画面 | 2つの盤面を並べて表示、置ける/置けない場所の色付きプレビュー、状況メッセージと戦況ログ |
| プレイヤーが船を配置 | クリック配置・回転・ランダム配置・やり直し |
| AIが自動で攻撃 | ハント＆ターゲット戦略。同じマスは二度攻撃しない |
| 命中・失敗の表示 | マスの色と記号、メッセージ、ログ |
| 撃沈の判定 | 全マス命中で撃沈、船リストに打ち消し線で表示 |
| 勝敗の表示 | 結果ダイアログ |
| 再スタート | いつでも「最初からやり直す」、終了後は「もう一度遊ぶ」 |
| テスト | Vitest でルール・AI・画面を自動テスト |
| Web公開 | GitHub Actions で GitHub Pages に自動デプロイ |

## 開発

Node.js 22 以上が必要です。

```sh
npm ci           # 依存パッケージをインストール
npm run dev      # 開発サーバー（http://localhost:5173）
npm test         # 自動テスト
npm run check    # 型チェック + テスト + 本番ビルド（PR前に実行）
```

## フォルダ構成

```
src/
  game/          ゲームのルール（画面に依存しない純粋なロジック）
    types.ts     盤面サイズ・船の種類などの定義
    board.ts     盤面：船の配置、攻撃の判定、撃沈・全滅の判定
    ai.ts        AI：次に攻撃するマスを決める
    game.ts      ゲーム進行：配置→対戦→終了、手番、勝者
  ui/app.ts      画面の描画とクリック操作
  main.ts        エントリーポイント
tests/           自動テスト（Vitest）
docs/            解説・バグレポート
.github/workflows/
  ci.yml         PRごとに型チェック・テスト・ビルド
  deploy.yml     main への push で GitHub Pages に公開
AGENTS.md        AIエージェント（Devin）向けの作業ルール
```

## 技術

TypeScript / Vite / Vitest（+ jsdom）。ランタイムの依存ライブラリはなく、サーバーも不要です（AIはブラウザ内で動作）。
