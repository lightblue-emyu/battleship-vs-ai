# Battleship vs AI

人間のプレイヤー1人がAI（コンピューター）と対戦できる、Web版 **Battleship（海戦ゲーム）** です。
マス目に隠れた相手の船の位置を予想して攻撃し、先に相手の船をすべて沈めた方が勝ちです。
濃紺と水色のスタイリッシュな画面で、ステルス艦風の軍艦を使って遊べます。対戦中に船を動かして攻撃をかわすこともできます。

- **遊ぶ**: https://lightblue-emyu.github.io/battleship-vs-ai/
- **しくみの解説（初心者向け・図あり）**: [docs/how-it-works.md](docs/how-it-works.md)
- **見つけたバグと修正内容**: [docs/bug-report.md](docs/bug-report.md)

## 遊び方

1. **船を配置する**：盤面の左半分（自陣）をクリックして5隻（空母5・戦艦4・巡洋艦3・潜水艦3・駆逐艦2）を置きます。
   「向きを変える」または `R` キーで縦横を切替。「ランダム配置」でおまかせもできます。
   配置中は「AIの強さ」で **弱い／普通／強い** を選べます（初期値は普通）。
2. **ゲーム開始**：すべて置いたら「ゲーム開始」を押します。
3. **攻守は1ターンごとに交代**（最初はあなたの攻撃）。毎ターン **5秒のシンキングタイム** があり、時間切れで実行されます。
   - **攻撃側**：狙うマスを決めます。あなたの攻撃なら敵陣（右半分）のマスをクリック（時間内なら変更・取り消しも可）。
     選ばないまま時間切れになると、そのターンは攻撃なしです。爆発が命中、青い輪が外れ。船の全マスに命中すると撃沈。
   - **守り側**：動かすなら船を1隻だけ動かせます。あなたの守りなら、自分の船をクリックして選び、光っているマスをクリック（または矢印キー）で移動先を決めます。
     時間切れになると、**先に守り側の船が動き、そのあとミサイルが発射** されます。うまく逃げれば攻撃をかわせます。
4. **移動できる範囲**：船の長さから被弾数を引いた数を N として、船の中心から **N×N の範囲**（無傷の空母なら上下左右に最大2マス）。
   被弾するたびに狭くなり、残りが1マス以下になると動けません。N が偶数のときは、右と下に1マス多く動けます。
   ほかの船や攻撃済みのマスは飛び越えられますが、ほかの船と重なる場所には止まれません。命中マークは船と一緒に動き、
   船が止まったマスの「外れ」の印は消えて、もう一度攻撃できるようになります。AIも守りのターンに船を動かします（どの船かは秘密）。
5. **勝敗**：相手の船を先に全部沈めた方の勝ち。「もう一度遊ぶ」/「最初からやり直す」で再スタートできます。

## 機能

| 要件 | 実装 |
| --- | --- |
| 操作しやすい画面 | 1つの盤面を中央線で「左＝自陣」「右＝敵陣」に分けて表示、置ける/置けない場所の色付きプレビュー、状況メッセージと戦況ログ |
| グラフィック | 濃紺×水色の画面（A案「ネイビー・タクティカル」）。上から見たステルス艦風の軍艦（自軍は右向き、敵は左向き）をSVGで描画、爆発・水しぶきのエフェクト |
| 艦隊の残存表示 | 右側のパネルに敵艦隊・自艦隊の残り隻数と、船ごとの「健在／被弾／撃沈」、どのマスに当たったか |
| 通算成績 | 右上に「何勝何敗・勝率」。ブラウザ（localStorage）に保存するので、ページを閉じても消えない |
| 動く海 | 盤面の下で波のうねりと日差しのきらめきがゆっくり動き続ける（CSSアニメーションのみ・アニメーションを減らす設定では静止） |
| 攻撃の演出 | 攻撃するとミサイルが光の尾を引いて、撃った側から狙ったマスへ約0.8秒で山なりに飛び、着弾すると結果が出る（アニメーションを減らす設定ではオフ） |
| 船の移動 | 守り側のターンに1隻を N×N（N＝長さ−被弾数）の範囲で動かせる。AIも狙われそうな船を動かす |
| シンキングタイム | 毎ターン5秒。攻撃側は狙うマス、守り側は動かす船を決め、時間切れで「移動 → 攻撃」の順に実行 |
| プレイヤーが船を配置 | クリック配置・回転・ランダム配置・やり直し |
| AIが自動で攻撃 | ハント＆ターゲット戦略。毎ターン盤面の印を見直すので、動いた船の命中マークも追いかける |
| AIの強さ | 弱い（ランダム・回避しない）／普通（ハント＆ターゲット）／強い（確率マップ・よく回避する）を配置中に選べる |
| 命中・失敗の表示 | マスの色と記号、メッセージ、ログ |
| 効果音 | 命中・撃沈のときにファミコン風の効果音（Web Audio APIで合成、音声ファイルなし）。「効果音：ON/OFF」で切り替え |
| 撃沈の判定 | 全マス命中で撃沈、艦隊パネルに「撃沈」と打ち消し線で表示 |
| 勝敗の表示 | 大きな「VICTORY / DEFEAT」の結果画面に、攻撃回数・命中率・残った自艦・通算成績 |
| 再スタート | いつでも「最初からやり直す」、終了後は「もう一度遊ぶ」 |
| テスト | Vitest でルール・AI・画面を自動テスト（97件） |
| Web公開 | GitHub Actions で GitHub Pages に自動デプロイ |

## 開発

Node.js 22 以上が必要です。

```sh
npm ci           # 依存パッケージをインストール
npm run dev      # 開発サーバー（http://localhost:5173）
npm test         # 自動テスト
npm run check    # 型チェック + テスト + 本番ビルド（PR前に実行）
```

## フォルダ構成

```
src/
  game/          ゲームのルール（画面に依存しない純粋なロジック）
    types.ts     盤面サイズ・船の種類などの定義
    board.ts     盤面：船の配置・移動、攻撃の判定、撃沈・全滅の判定
    ai.ts        AI：強さ（弱い・普通・強い）に応じて次に攻撃するマスや、狙われた船を逃がすかどうかを決める
    game.ts      ゲーム進行：配置→対戦→終了、手番、勝者
  ui/app.ts      画面の描画とクリック操作
  ui/sprites.ts  船・爆発・ミサイルのイラスト（SVG）
  ui/record.ts   通算成績（localStorageに保存）
  ui/missile.ts  攻撃ミサイルの弾道計算と飛ぶアニメーション
  ui/sound.ts    命中・撃沈の効果音（Web Audio APIで合成）
  ui/sea.css     盤面の下で動く海（波のうねり・光のきらめき）
  main.ts        エントリーポイント
tests/           自動テスト（Vitest）
docs/            解説・バグレポート
.github/workflows/
  ci.yml         PRごとに型チェック・テスト・ビルド
  deploy.yml     main への push で GitHub Pages に公開
AGENTS.md        AIエージェント（Devin）向けの作業ルール
```

## 技術

TypeScript / Vite / Vitest（+ jsdom）。フォントは Google Fonts（Inter / Noto Sans JP / Orbitron）を読み込みます。ランタイムの依存ライブラリはなく、サーバーも不要です（AIはブラウザ内で動作）。
